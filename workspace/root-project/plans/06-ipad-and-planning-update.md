# iPad update and collection planning

> Historical device/build snapshot. Current requirements are mobile/touch-first with clubhouse portrait and landscape on phones, plus iPad and PC. See the [consolidated requirements](20-application-requirements.md). Old game counts below are not current readiness claims.


Stormglide's local source and offline playable are now touch-first. Controls use relative thumb steering, a visible pad, lift-to-stop, a large second-thumb Dash button, enlarged touch targets, and rotation/interruption cleanup. Keyboard and mouse remain supported. The painted background is cached to reduce per-frame work on tablets.

The prior source-migration verification was completed before these behavior changes. Touch behavior has automated event tests; physical iPad Safari playtesting has not been performed. The existing public Site still serves the earlier release.

The ten titles from Jobe's photo are now cataloged, with a folder and logged pitch for each. Stormglide is implemented; the remaining nine are proposed only. Meta-game and multiplayer work is documentation only.
