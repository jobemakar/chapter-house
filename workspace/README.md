# Battle of the Books workspace snapshot

This directory preserves the planning and catalog material that lives beside the
Chapter House application in the local `battle-of-books` workspace. The
application itself remains at the repository root so its existing build,
deployment, and standalone game-package workflows continue to work.

- `root-project/` contains the workspace README, catalog, persistent project
  guidance, root ignore rules, and complete planning history as of the commit
  that added this snapshot.
- `archive/README.md` documents the local recovery archive. The compressed
  archive is published separately as a GitHub release asset because its size
  exceeds GitHub's normal Git object limit.

The reusable legacy design notes have also been consolidated under
`docs/legacy-game-notes/` for ordinary iteration and search.
