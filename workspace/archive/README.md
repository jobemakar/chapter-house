# Legacy book-game source archive

`legacy-book-game-sources-2026-09-19.tar.gz` contains the ten former top-level
book repositories, including source, assets, builds, standalone playables, Git
history, and the uncommitted working-tree state present when they were retired.

`repositories/` is the directly browsable recovery copy of those same retired
repositories. Keeping it below this single archive directory removes the ten
book directories from the collection root without discarding their independent
Git histories.

Only reinstallable `node_modules` and generated coverage caches were omitted.

SHA-256:

`B1F450BD8DEC591E456E31FD0A87780FD3DCF1C651F7B4596280CACE7B64B425`

The extracted, searchable first-party notes and historical game manifests live
in `application/docs/legacy-game-notes/`. The canonical runnable games live in
`application/packages/`.
