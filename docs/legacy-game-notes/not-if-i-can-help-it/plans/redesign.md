# Gummy Nook — revision plan

2026-09-10 · BOB-006-R2 · proposed-revised. Not implemented.

Squish and combine colorful gummies in a satisfying little tray, discovering shapes that become ornaments and furniture for a cozy corner. Keep free rearrangement and adjustable sound/motion. Gummy and comfort themes are intentionally loose; the outer-space framing is retired.

## Primary mechanic
Squishy merge-and-shape discovery board.

## Proposed placeable rewards
Gummy-bear beanbag, candy lamp, soft sock cushion and candy jar. These are original thematic extensions, not claimed literal objects from the book.
