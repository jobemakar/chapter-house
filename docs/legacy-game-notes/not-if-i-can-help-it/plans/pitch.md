# Gummy Galaxy — proposed concept

Date: 2026-09-10
Book: *Not If I Can Help It* by Carolyn Mackler
Idea: BOB-006
Status: proposed only; no game source or playable has been generated.

Drop, stretch, and squish jewel-colored gummy shapes into a satisfying little world. Matching gummies combine into increasingly delightful creations, and gentle chain reactions reveal new shapes. There’s always a way to make room—no overflowing-board game over and no noisy surprise effects.

## Mechanic signature
- Input: Drag and drop shapes; pull large stretch handles; tap a free scoop tool.
- Primary verbs: place, squish, merge, discover.
- Loop: Position shapes → trigger a merge chain → discover a new form → rearrange and continue.
- Spatial structure: A contained soft-body board with reversible cleanup.
- Recoverable friction: Crowding can be cleared with a free scoop/rearrangement; earned discoveries remain.
- Progression: Shape collection, palettes, board themes, gentle texture effects.
- Art: Translucent candy glass, clean aqua and peach palette, calm optional sound.
- Audio: original or properly licensed music/effects with immediate mute; specific sound design to be selected before implementation.

## Distinctness
The only merge/discovery board. It does not model sensory processing differences as a defect, challenge meter, or thing to cure; the candy inspiration is a loose cover motif.

## Before implementation
If this concept is selected, write numbered requirements from the shared template, specifying controls, timing, recovery, visual/audio treatment, progression, save behavior, and acceptance checks. Do not treat this pitch as authorization to build the game.

## Potential shared-world reward
A squishy gummy beanbag and translucent lamps.
