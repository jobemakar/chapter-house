# Door Atelier

Original Three.js miniature-door puzzle experiment inspired only by the inspectable rotating-diorama format. Install and run:

```powershell
npm install
npm run dev
npm test
npm run build
```

`dist/index.html` is the reproducible standalone entry after `npm run build`; the build bundles all game code and uses no remote assets. See [REQUIREMENTS.md](REQUIREMENTS.md) for puzzle walkthroughs and scope.
