# Emberwatch — proposed concept

Date: 2026-09-10
Book: *Wildfire* by Rodman Philbrick
Idea: BOB-009
Status: superseded historical proposal. The selected local prototype is [Dig & Douse](design.md).

Command a tiny forest-rescue crew from above. Send water drops, open safe corridors, and outmaneuver drifting cartoon embers as the wind changes. The map is always moving, but setbacks become smoky detours and regrowth opportunities—not a lost campaign.

## Mechanic signature
- Input: Tap hotspots to assign water crews; drag broad protective lines and safe routes.
- Primary verbs: prioritize, contain, redirect, restore.
- Loop: Read changing hotspots → allocate a few active tools → create breathing room → adapt as the wind changes.
- Spatial structure: An evolving top-down map with spreading environmental pressure.
- Recoverable friction: Smoke temporarily blocks an area; tools replenish and the forest can recover. No playable child faces a death state.
- Progression: Crew tools, forest regions, restored groves, rescue badges.
- Art: Stylized papercraft forest, ember orange against teal water, clear readable map.
- Audio: original or properly licensed music/effects with immediate mute; specific sound design to be selected before implementation.

## Distinctness
Unique pressure-containment and resource-priority loop. Unlike Sanctuary Seasons, success depends on reacting to a moving situation, not long-term habitat construction. Fictional arcade abstraction, not survival instruction.

## Before implementation
This proposal was not selected for the current prototype. It is retained so its distinct mechanic and reward ideas are not lost.

## Potential shared-world reward
A glowing camp lantern and a regrowing miniature forest.
