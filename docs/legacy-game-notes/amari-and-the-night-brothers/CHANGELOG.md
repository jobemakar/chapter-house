# Changelog

## Toolchain migration — 2026-09-19

- Added this repository's pinned `package.json`, lockfile and strict TypeScript
  configuration. `npm ci`, `npm run typecheck`, `npm test`, `npm run build` and
  `npm run check` no longer require or inspect the sibling application install.
- This is not a source port: the existing TypeScript/OOP domain, game, artwork,
  two floors, generated playable identity and artifact-size guard remain intact.
- Preserved `bureau-after-dark:progress:v2`, `bureau-after-dark:muted`, both
  reward IDs and the duplicate-safe reward claim behavior. The v1 prototype
  archive remains untouched. No publication occurred.

## 0.3.0 — 2026-09-17

- Richly illustrated Night Garden Case File and Lanternwing Cryptid Record cards,
  with readable case/field notes, catalogue details and collection revisits.
- Twelve generated neutral search-object illustrations replace labeled ovals.
  Existing tap-to-walk/search, keyboard controls and state indicators remain.
- Generated slate floor texture and illustrated shelves enrich the dark Bureau
  without competing with sigils and final cards.
- Same floors, riddles, ordering, reward IDs and durable save format/key.
- Original PNGs/provenance preserved; reward/floor distribution WebPs use quality
  90 encoding without resizing/cropping. Transparent object PNG alpha is retained.

Canonical source rebuilt and Chapter House snapshot refreshed. Hosting receipt
is recorded in parent plan 45 after publication.

## 0.2.0 — 2026-09-17 (local)

- Two floors with six neutral search spots each, three hidden sigils each, and shelf-safe walking.
- Automatic elevator exit, pleasant discovery chimes, persistent mute.
- Animated parchment, tap/scrub reveal, generic riddle heading and retryable choices.
- Six original generated sigil images, animated stardust, tap-to-journal transition and matching smaller icons with names/order clues.
- Archive sequence puzzle, saved Night Garden case file and Lanternwing cryptid record, gated second floor.
- Validated browser-local saves, session fallback, keyboard dialog controls and reduced-motion support.
- Readable TypeScript sources, reproducible embedded-art HTML build and preserved original prototype.

The user explicitly chose riddles, superseding the original disguise/stealth proposal. This revision updates the local standalone preview only.
