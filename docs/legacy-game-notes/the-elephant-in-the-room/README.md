# The Elephant in the Room

Author: Holly Goldberg Sloan

Canonical game: **Veda's Great Escape** (BOB-008).

Guide Veda through five gentle grid puzzles on her way to the sanctuary. Push
crates onto golden switches, collect optional peaches, then reach the open exit.
Undo, restart and solver-backed hints make every mistake recoverable.

[Pitch and mechanic comparison](plans/pitch.md) · [Collection rules](../AGENTS.md) · [All ten pitches](../plans/03-ten-game-pitches.md)

Status: implemented locally as a strict TypeScript npm workspace package. The
same gameplay implementation runs independently on port 5201 and lazy-loads in
Chapter House. The earlier Sanctuary Seasons habitat proposal is superseded but
retained in repository history. No backend or publication is implied.
