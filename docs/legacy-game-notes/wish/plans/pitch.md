# Wishbone’s Big Fetch — proposed concept

Date: 2026-09-10
Book: *Wish* by Barbara O'Connor
Idea: BOB-003
Status: original pitch selected on 2026-09-10; local 0.1.0 demo implemented. See requirements.md and design.md for the actual demo scope.

Pull back a frisbee and send it skipping through a sunlit backyard full of ramps, wind chimes, and ridiculous ricochets. Wishbone chases every throw, even the gloriously bad ones. Discover trick-shot routes and turn an ordinary game of fetch into a joyful stunt playground.

## Mechanic signature
- Input: Drag to aim and set power; release to throw.
- Primary verbs: aim, launch, bounce, fetch.
- Loop: Choose a target path → make a throw → watch the ricochets and dog chase → immediately throw again.
- Spatial structure: One playful yard diorama at a time; discrete projectiles.
- Recoverable friction: Misses become goofy fetch animations; the disc always returns, with no lives or reload screen.
- Progression: New discs, yards, trick-shot badges, dog accessories.
- Art: Warm watercolor summer, chalk trails, paper-textured gardens.
- Audio: original or properly licensed music/effects with immediate mute; specific sound design to be selected before implementation.

## Distinctness
Unlike Stormglide, movement is not continuously steered. Unlike Popcorn, the player directly launches each projectile rather than constructs a machine.

## Before implementation
If this concept is selected, write numbered requirements from the shared template, specifying controls, timing, recovery, visual/audio treatment, progression, save behavior, and acceptance checks. Do not treat this pitch as authorization to build the game.
