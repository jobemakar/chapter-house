# Legacy game notes

These files preserve the first-party Markdown notes and historical `game.json`
manifests that lived in the ten former top-level book repositories. They remain
searchable here for future game iteration after the canonical implementations
moved to `application/packages/`.

The notes are historical. Paths, commands, versions, and readiness claims in an
individual file describe its original repository at the time and may no longer
match the current workspace package. Use
`../workspace-game-package-migration-log.md` for the current package ledger.

The complete source trees, assets, generated playables, Git histories, and
uncommitted working trees are preserved in:

`archive/legacy-book-game-sources-2026-09-19.tar.gz`
