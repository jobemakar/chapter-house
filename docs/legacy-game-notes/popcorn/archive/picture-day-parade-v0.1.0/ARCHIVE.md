# Picture Day Parade v0.1.0 archive

Archived on 2026-09-19 when Contraption (BOB-010-R3) became Popcorn's canonical local game. This directory is a complete runnable preservation of Picture Day Parade: original `src`, `tests`, `dist`, direct-file `playable`, build script, package manifest, plans, and the `picture-day-parade.v1` save key. It has no shared save-state with Contraption.
