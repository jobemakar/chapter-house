# Popcorn Contraption Club — proposed concept

Date: 2026-09-10
Book: *Popcorn* by Rob Harrell
Idea: BOB-010
Historical status: proposed on 2026-09-10; subsequently implemented, expanded into six authored levels, and selected as the canonical game on 2026-09-19.

Build the world’s least sensible popcorn machine. Place fans, funnels, trampolines, and conveyor belts, then watch kernels bounce into a spectacular chain reaction. Keep rearranging the machine while it runs; escaped popcorn circles back for another try.

## Mechanic signature
- Input: Drag machine parts; tap to rotate; move pieces while the simulation runs.
- Primary verbs: build, route, trigger, tinker.
- Loop: Place a device → watch moving popcorn → adjust the chain → unlock another ridiculous component.
- Spatial structure: A side-view construction sandbox with continuous circulating projectiles.
- Recoverable friction: Spills automatically recirculate; unlimited editing and undo, with no destruction of collected rewards.
- Progression: Machine parts, chain-reaction discoveries, themed workshops.
- Art: Loose comic ink, buttery yellow, blue doodles, elastic cartoon motion.
- Audio: original or properly licensed music/effects with immediate mute; specific sound design to be selected before implementation.

## Distinctness
Unlike Wish's direct trick shots, the player designs a reusable machine; unlike Pocket Funhouse, the player assembles new mechanisms rather than solves an authored room. Anxiety is not represented as a failure meter or joke.

## Before implementation
If this concept is selected, write numbered requirements from the shared template, specifying controls, timing, recovery, visual/audio treatment, progression, save behavior, and acceptance checks. Do not treat this pitch as authorization to build the game.

## Potential shared-world reward
A working miniature popcorn machine for the clubhouse.
