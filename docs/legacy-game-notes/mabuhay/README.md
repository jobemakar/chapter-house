# Moonlight Munch Run

Canonical local Mabuhay-inspired illustrated traveling food shooter. Automatic forward
servings, 2D steering, catchable retained shot upgrades, independent rapid fire,
supply/restock recovery, three waves then a boss, rechargeable special serving.
Guests drop avoid-only potholes and spore pods: contact jams all firing for one
second. Generated frame atlases animate the truck, wings, feet and boss details;
reduced motion holds a stable frame. See assets/FRAME-AND-HAZARD-PROVENANCE.md.
